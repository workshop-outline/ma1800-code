# MA1800 Coding Resources

This repository contains completed coding workshop examples for MA1800.

The workshops focus on HTML and CSS for creative and web-based artistic practice. The repository is organised by teaching week. Each week contains a simple index page linking to the completed version of each workshop.

## Structure

- `index.html` — main page for the repository
- each week has its own folder and `index.html`
- each workshop has its own `index.html`
- additional pages use names such as `page1.html`, `page2.html`
- CSS is usually stored in `style.css`
- images, GIFs, audio and video are stored in an `assets/` folder where needed

The repository is set up to work with GitHub Pages.
