# MA1800: Introduction to Digital Media Practice

This repository contains completed coding workshop examples for MA1800.

The workshops focus on HTML and CSS for creative and web-based artistic practice. The repository is organised by teaching week. Each week contains a simple index page linking to the completed version of each workshop.

## Structure

- `index.html` — main workshop index
- `week-XX-.../index.html` — index for that week
- each workshop folder contains its own `index.html`
- additional pages use `page1.html`, `page2.html`, and so on
- workshop styles use `style.css`
- workshop media is stored locally in an `assets/` folder where needed

The repository is designed to work directly with GitHub Pages.
