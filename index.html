MA1800 Coding Workshops

Completed HTML and CSS workshop examples for MA1800: Introduction to Digital Media Practice. Open a week below, then select a workshop to view its completed version.

  1. Week 1 — HTML Basics
    HTML document structure, headings, paragraphs, line breaks and horizontal rules.
  2. Week 2 — Hypertext and Images
    Hyperlinks, multi-page structures, HTML tags and local images.
  3. Week 3 — Introduction to CSS
    External stylesheets, divs, classes, IDs, hover states and background images.
  4. Week 4 — Positioning and Layout
    CSS positioning, Flexbox, image-and-text layouts and repeated content blocks.
  5. Week 5 — GIFs and Web Images
    Embedding animated GIFs and combining multiple moving images in a webpage.
  6. Week 6 — CSS Animation
    Keyframes, rotation, colour changes and animation delays.
  7. Week 7 — CSS Interaction and Experimental Layout
    Movement, hover interaction, split-screen choices and combining animation techniques.
  8. Week 8 — Navigation and Page Structures
    Multi-page navigation, persistent navigation, image posts and flexible galleries.
  9. Week 9 — Building and Refining Your Website
    Semantic HTML, accessible navigation, responsive layouts and audio/video.
  10. Week 10 — Development and Submission
    Testing, debugging, publishing and final submission checks.
