# Week 1 — HTML Basics

This week introduces the core building blocks of HTML. You’ll learn how to structure a webpage, add text, and work with line breaks and horizontal rules.

## Workshops
- **Hello World** — basic HTML document structure, heading and paragraph.
- **Headings and Paragraphs** — heading levels, paragraphs and simple text formatting.
- **Line Breaks and Horizontal Rules** — use `<br>` and `<hr>` to structure content.
