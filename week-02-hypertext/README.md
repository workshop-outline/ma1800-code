# Week 2 — Net.Art and Hypertext

This week explores hypertext — linking between pages — and connects this to early net.art practices.

## Workshops
- **Hyperlinks** — link one HTML page to another.
- **Hypertext** — create a small non-linear structure across multiple pages.
- **HTML Tags** — experiment with a wider range of HTML elements.
- **Images** — load images from a web address and from a local `assets/` folder.
