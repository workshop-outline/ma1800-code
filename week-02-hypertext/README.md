# Week 2 — Hypertext and Images

This week explores hypertext, linking between pages, and image paths.

## Workshops
- **Hyperlinks** — Connect one HTML page to another and link to an external website.
- **Hypertext Choices** — Build a small non-linear structure using several HTML pages.
- **HTML Tags** — Experiment with headings, lists, buttons, text areas and preformatted text.
- **Images** — Load an image from a URL and from a local assets folder.
