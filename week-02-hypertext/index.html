Week 2 — Hypertext and Images

Explore hyperlinks and multi-page structures, then add images and a wider range of HTML elements.

Workshops

  1. Hyperlinks — Connect one HTML page to another and link to an external website.
  2. Hypertext Choices — Build a small non-linear structure using several HTML pages.
  3. HTML Tags — Experiment with headings, lists, buttons, text areas and preformatted text.
  4. Images — Load an image from a URL and from a local assets folder.
