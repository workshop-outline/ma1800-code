Week 3 — Introduction to CSS

Use an external stylesheet to change how HTML elements look and behave.

Workshops

  1. Linking CSS — Connect an external stylesheet and change colours, fonts and text size.
  2. Div Containers — Group HTML elements and style the group as a block.
  3. Classes and IDs — Apply reusable classes and a unique ID to selected elements.
  4. Hover Effects — Use the CSS :hover state to reveal hidden text.
  5. Background Images — Apply a local image as a repeating CSS background.
