# Week 4 — Positioning and Layout

This week focuses on CSS positioning, Flexbox and repeated layout structures.

## Workshops
- **CSS Positioning** — Compare normal flow with relative, absolute and fixed positioning.
- **Find the Cat** — Use absolute and fixed positioning to place clues across a large page.
- **Flexbox Ratios** — Distribute space between blocks using Flexbox.
- **Image and Text** — Combine an image, caption and longer text in one layout.
- **Repeated Content Blocks** — Use classes to style a repeating timeline or feed.
