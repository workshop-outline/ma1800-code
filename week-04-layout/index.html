Week 4 — Positioning and Layout

Explore different ways of placing and arranging content with CSS.

Workshops

  1. CSS Positioning — Compare normal flow with relative, absolute and fixed positioning.
  2. Find the Cat — Use absolute and fixed positioning to place clues across a large page.
  3. Flexbox Ratios — Distribute space between blocks using Flexbox.
  4. Image and Text — Combine an image, caption and longer text in one layout.
  5. Repeated Content Blocks — Use classes to style a repeating timeline or feed.
