# Week 5 — GIFs and Web Images

This week connects GIF-making with the HTML and CSS skills already introduced.

## Workshops
- **Single GIF** — Embed a locally stored animated GIF with the image tag.
- **Multiple GIFs** — Place several animated GIFs on one page and style them with CSS.

## Notes
Store your GIF files inside the workshop's `assets/` folder and reference them with a relative path.
