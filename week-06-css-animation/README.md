# Week 6 — CSS Animation

This week introduces CSS animation using `@keyframes` and animation properties.

## Workshops
- **Spinning Text** — Introduce @keyframes by rotating a heading.
- **Animated Letters** — Animate individual letters and connect to a second page.
- **Colour Animation** — Cycle text through several colours over time.
- **Sequential Messages** — Use animation-delay to reveal messages in sequence.
