Week 6 — CSS Animation

Use CSS keyframes to create movement, colour changes and timed sequences.

Workshops

  1. Spinning Text — Introduce @keyframes by rotating a heading.
  2. Animated Letters — Animate individual letters and connect to a second page.
  3. Colour Animation — Cycle text through several colours over time.
  4. Sequential Messages — Use animation-delay to reveal messages in sequence.
