# Week 7 — CSS Interaction and Experimental Layout

This week combines movement, hover states, hypertext and layout.

## Workshops
- **Moving Elements** — Animate the position of text inside a defined space.
- **Hover Reveal** — Layer two images and reveal the second image on hover.
- **Split-Screen Choices** — Create two visual choices that link to different pages.
- **Combining Techniques** — Combine local images, GIFs and CSS animation in one composition.
