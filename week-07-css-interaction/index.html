Week 7 — CSS Interaction and Experimental Layout

Bring together techniques from earlier weeks to create more responsive and experimental web compositions.

Workshops

  1. Moving Elements — Animate the position of text inside a defined space.
  2. Hover Reveal — Layer two images and reveal the second image on hover.
  3. Split-Screen Choices — Create two visual choices that link to different pages.
  4. Combining Techniques — Combine local images, GIFs and CSS animation in one composition.
