# Week 8 — Navigation and Page Structures

This week focuses on navigation, repeated page structures and larger website organisation.

## Workshops
- **Multi-Page Navigation** — Keep the same navigation menu across several pages.
- **Persistent Navigation Tray** — Build a two-page article with a fixed tray at the bottom.
- **Image Posts and Captions** — Organise repeated image-and-caption blocks in a single column.
- **Flexible Image Gallery** — Use Flexbox and wrapping to create a responsive image collection.
