# Week 9 — Building and Refining Your Website

This week focuses on practical refinements that help a larger HTML/CSS project work reliably across pages and screen sizes.

## Workshops
- **Semantic HTML** — Organise a page with header, nav, main, section, article and footer.
- **Accessible Navigation** — Write clear links, alt text and visible keyboard focus states.
- **Responsive Layout** — Use a media query to adapt a two-column page for smaller screens.
- **Audio and Video** — Embed local audio and video files with native HTML media elements.
