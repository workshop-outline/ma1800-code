Week 9 — Building and Refining Your Website

Refine the structure, accessibility and adaptability of a developing web-art project.

Workshops

  1. Semantic HTML — Organise a page with header, nav, main, section, article and footer.
  2. Accessible Navigation — Write clear links, alt text and visible keyboard focus states.
  3. Responsive Layout — Use a media query to adapt a two-column page for smaller screens.
  4. Audio and Video — Embed local audio and video files with native HTML media elements.
