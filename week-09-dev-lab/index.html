Week 9 — CSS Interactivity

We begin this week with three exercises that focus on interaction inside the browser: first by hovering to reveal an image, then animating messages with timed delays, and finally placing text inside an iPhone frame to simulate a scrolling feed. These build on your HTML and CSS skills.

Workshops

  1. Exercise 1 — Hover to Reveal an Image
  2. Exercise 2 — Animated Messages with Delays
  3. Exercise 3 — iPhone Simulation with Scrollable Text
