Week 10 — Development and Submission

There is no new coding technique this week. Use the session to test, debug, publish and prepare your own project.

Final checks

  • Open every page and test every internal link.
  • Check that local image, GIF, audio and video paths work.
  • Check the project at more than one browser-window size.
  • Make sure important images have useful alt text.
  • Confirm that index.html is the main entry page.
  • Publish the current version through GitHub Pages and test the public URL.
  • Prepare the required submission files separately according to the assessment instructions.
